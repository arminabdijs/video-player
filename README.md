# Aura Material Video Player Pro

این نسخه، طراحی و ساختار پلیر اصلی را حفظ می‌کند و قابلیت خواندن زیرنویس‌های متنی تعبیه‌شده در فایل‌های MKV را به همان منوی زیرنویس اضافه می‌کند.

## چه چیزی اصلاح شده؟

- تشخیص ترک‌های زیرنویس داخل MKV بدون نیاز به انتخاب فایل جداگانه.
- پشتیبانی از ترک‌های متنی `S_TEXT/UTF8`، `S_TEXT/ASS`، `S_TEXT/SSA` و `S_TEXT/WEBVTT`.
- انتخاب بین چند ترک داخلی، انتخاب زبان/ترک پیش‌فرض و برگشت به فایل زیرنویس جداگانه.
- خواندن فایل با `Blob.slice()` و رد کردن داده‌های صوتی/تصویری، به‌جای بارگذاری کامل ویدئو در حافظه.
- استفاده از `TextTrackList` مرورگر برای فرمت‌هایی که خود مرورگر ترک زیرنویس را در دسترس جاوااسکریپت قرار می‌دهد.
- حفظ قابلیت قبلی فایل‌های جداگانهٔ SRT و VTT و تنظیمات ظاهری زیرنویس.

## اجرا

پروژه استاتیک است و برای اجرای معمول به نصب پکیج یا بیلد نیاز ندارد. `index.html` را از طریق یک وب‌سرور محلی یا GitHub Pages باز کنید. برای انتخاب پوشه و خواندن فایل‌های محلی، مرورگرهای Chromium-based توصیه می‌شوند.

## تست‌های داخلی

با Node.js نسخهٔ ۱۸ یا جدیدتر:

```bash
npm test
```

تست‌ها ساختارهای نمونهٔ Matroska، زمان‌بندی، زیرنویس ASS، Segment/Cluster با اندازهٔ نامشخص و تشخیص ترک تصویری PGS را بررسی می‌کنند.

## محدودیت‌هایی که باید بدانید

- ترک‌های تصویری **PGS** و **VobSub** شناسایی می‌شوند، ولی رمزگشایی و نمایش تصویر آن‌ها در این تغییر پیاده‌سازی نشده است.
- زیرنویس واقعاً حک‌شده در پیکسل‌های تصویر، ترک قابل انتخاب نیست؛ باید به‌صورت بخشی از خود تصویر ویدئو دیده شود. این تغییر برای ترک‌های زیرنویس جدا از تصویر داخل کانتینر است.
- این تغییر قابلیت رمزگشایی کدک یا کانتینر جدیدی به مرورگر اضافه نمی‌کند؛ پخش خود ویدئو همچنان به پشتیبانی مرورگر از فایل وابسته است.
